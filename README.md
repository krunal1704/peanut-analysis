# peanut-analysis

This repository contains the data analysis scripts and statistical processing code used to evaluate plant growth-promoting rhizobacteria (PGPR) efficacy on peanut development. The pipeline processes phenotypic measurements (including total plant height, root length, shoot length, and dry weight) from both sterile and non-sterile soil experiments across multiple time points (45 and 120 days), performing data wrangling, ANOVA, and post-hoc comparisons to generate the reported statistical metrics
